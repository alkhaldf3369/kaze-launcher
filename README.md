# Kaze 🌸

واجهة خفيفة وأنيقة لتلفزيونات Google TV و Android TV، بدون إعلانات.

- خلفية متحركة أصلية بطابع أنمي (سما ليل، قمر، بتلات ساكورا، يراعات)، أو صورك وGIF وفيديوهاتك أنت.
- صف واحد لتطبيقاتك المفضلة فقط، والباقي في "كل التطبيقات".
- براوزر مدمج لموقع CinJoy: يفتح على آخر صفحة كنت فيها، يمنع النوافذ المنبثقة والإعلانات، ومؤشر يتحرك بأسهم الريموت.
- زر الهوم يفتح Kaze (عن طريق خدمة إمكانية الوصول "Kaze: زر الهوم"). الضغط المطوّل على الهوم يفتح لوحة قوقل.

## التثبيت
افتح تطبيق Downloader على التلفزيون واكتب الرابط:

```
https://github.com/alkhaldf3369/kaze-launcher/releases/latest/download/Kaze.apk
```

## الخلفيات
حط صورك (jpg, png, webp)، أو GIF، أو فيديو (mp4) في:

```
/sdcard/Android/data/dev.kaze.launcher/files/wallpapers/
```

## الريموت داخل البراوزر
| الزر | الوظيفة |
|---|---|
| الأسهم | تحريك المؤشر (يسرع مع الضغط المستمر)، ويمرر الصفحة عند الحافة |
| OK | ضغط |
| رجوع | الصفحة السابقة |
| رجوع مطوّل أو Menu | القائمة |
| تشغيل/إيقاف، تقديم، ترجيع | يتحكم بالفيديو |
